# 🌱 EcoSort AI - 智慧垃圾分類與減量助手

> 一款結合 Google Gemini AI 視覺辨識的智慧環保 Web 應用，讓使用者能透過**手機/電腦相機即時掃描**或**直接選取相簿照片**，快速辨識垃圾種類、確定投遞桶別，並獲得日常生活中「源頭減量」的具體行動建議。

---

## ✨ 核心特色與功能

1. **相簿相片與相機鏡頭雙重支援**
   - 點擊「開啟相簿選取照片」直接上傳相片、截圖進行辨識。
   - 支援後鏡頭/前鏡頭即時影像掃描、雷射框對準與快門拍照。
   - 支援將相片直接拖曳至視窗辨識。
   - 內建手搖杯、便當盒、電池、廚餘等預設測試樣品，手邊沒垃圾也能隨時體驗。

2. **精準分類與多材質部件拆解**
   - 依據台灣環保署資源回收分類標準（紙容器、塑膠回收、生廚餘、熟廚餘、有害垃圾、一般垃圾）。
   - 針對複合材質（如手搖飲料杯、紙餐盒）進行細部分解，指引杯身、杯蓋、吸管、封膜分別丟棄於何處。
   - 互動式 5 步驟處置檢核表（倒空、拆解、沖洗、瀝乾、分類）。

3. **日常減廢生活提案（源頭減量建議）**
   - 不只教你如何丟，更告訴你如何少製造垃圾！每項分析均附 2~4 點實用的日常減量撇步（如自備環保杯享折扣、循環容器服務、充電電池替代一次性電池等）。

4. **語音朗讀播報**
   - 內建語音朗讀按鈕（Web Speech API），長輩與忙碌雙手也能輕鬆聆聽分類重點。

5. **分類圖鑑與知識測驗**
   - **分類圖鑑**：搜尋常見易混淆物品（感熱紙發票、吸油披薩紙、大骨頭、氣泡袋等）的避坑指南。
   - **環保測驗**：挑戰 7 題隨堂測驗，通關獲得專屬環保徽章！

6. **減碳點數與掃描歷程**
   - 正確分類丟棄獲得綠色點數與紙花獎勵，自動累計減碳效益（kg CO₂）。

## 🛠️ 技術架構

- **前端**：React 19、TypeScript、Vite、Tailwind CSS、Lucide React、Canvas-Confetti
- **後端**：Express、Node.js
- **AI 核心**：Google Gen AI SDK (`@google/genai`)
  - 預設模型：`gemini-3.8-flash`（自動支援高負載容錯與重試）

## 🚀 快速安裝與啟動教學

### 步驟 1：取得專案代碼並進入目錄
```bash
git clone <你的專案儲存庫網址>
cd <專案資料夾名稱>
```

### 步驟 2：安裝相依套件
```bash
npm install
```

### 步驟 3：設定環境變數
在專案根目錄下建立或修改 `.env` 檔案，填入您的 Gemini API Key：

```env
# Gemini API Key（可在 Google AI Studio 免費取得）
GEMINI_API_KEY="你的_GEMINI_API_KEY"

# 服務埠號（選填，預設為 3000）
PORT=3000
```

> 💡 **如何取得 API Key？**
> 前往 [Google AI Studio](https://aistudio.google.com/) 點擊 **Get API key**，即可免費建立專屬的 API Key。

### 步驟 4：啟動開發伺服器
```bash
npm run dev
```

終端機顯示伺服器已啟動後，請在瀏覽器打開：
```
http://localhost:3000
```

## 📋 常見問題與使用秘訣 (FAQ)

1. **使用相機時提示「無法存取鏡頭」？**
   - 請檢查瀏覽器網址列右側的相機權限設定，將權限設為「允許」。
   - 若在非 HTTPS 環境或無相機的桌機上，可直接點選**「開啟相簿選取照片」**進行辨識。

2. **上傳照片的格式與大小限制？**
   - 支援 JPG、PNG、WebP、HEIC（轉成標準格式）等主流圖檔。
   - 伺服器已配置高達 25MB 的照片容量解析限制。

3. **辨識結果如何確保準確？**
   - 拍攝時請將垃圾置於畫面正中央、確保光線充足，避免過多雜物干擾。
   - 若物品有特殊污損情況（例如沾滿濃厚油污），可使用卡片下方的「問問 AI」進一步輸入詢問。
